Block training bots without losing AI citations

The mistake: one rule blocks "AI bots" and kills ChatGPT/Perplexity citations for 2 weeks. The fix: split training (block) vs search-index (allow 120/min) vs user-triggered (never throttle) — exactly what the analyzer's 75-signature DB does.

1. robots.txt split (RFC 9309 most-specific-wins)

User-agent: GPTBot
Disallow: /
User-agent: ClaudeBot
Disallow: /
User-agent: CCBot
Disallow: /
User-agent: Bytespider
Disallow: /
User-agent: Google-Extended
Disallow: /
User-agent: OAI-SearchBot
Allow: /
User-agent: PerplexityBot
Allow: /
User-agent: Claude-SearchBot
Allow: /
User-agent: *
Allow: /

2. Cloudflare WAF rules

# Rule 1 — training bots: Managed Challenge, 60/min (20 aggressive)
(http.user_agent contains "GPTBot") or (http.user_agent contains "ClaudeBot")
or (http.user_agent contains "CCBot") or (http.user_agent contains "Bytespider")
# Rule 2 — search-index: ALLOW, rate-limit 120/min, 429 + Retry-After only
# Rule 3 — user-triggered (ChatGPT-User, Perplexity-User): DO NOT throttle
